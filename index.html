Phase 2 — Developer Skills

Virtual Environments (venv)

Description: Learn to create isolated Python environments to manage project dependencies.

  1. Open terminal or command prompt.
  2. Run python -m venv myenv to create a virtual environment.
  3. Activate with source myenv/bin/activate (Linux/Mac) or myenv\\Scripts\\activate (Windows).
  4. Install dependencies using pip install package_name.
Official Python Docs

Python Modules & Packages

Description: Learn to structure Python code using modules and packages.

  1. Create a Python file my_module.py.
  2. Import it in another script using import my_module.
  3. Create folders with __init__.py to make packages.
  4. Test importing and running functions.

Phase 3 — Discord Bot Basics

Discord Developer Portal & Bot Creation

Description: Create a bot in Discord Developer Portal and get a token.

  1. Go to Discord Developer Portal.
  2. Click 'New Application' and name it.
  3. Go to Bot tab and click 'Add Bot'.
  4. Copy the bot token and store it securely.
  5. Invite bot to your server using OAuth2 URL.

Phase 4 — Advanced Discord Development

Command Handling & Cogs

Description: Organize your bot commands and events using cogs.

  1. Create a folder cogs and Python files for each module.
  2. Use from discord.ext import commands to define commands in cogs.
  3. Load cogs in main bot file using bot.load_extension('cogs.filename').
  4. Test each cog individually.
Cogs Documentation

Databases for Bots

Description: Learn to store persistent data for your bot using SQLite or MySQL.

  1. Install SQLite (built-in) or MySQL connector: pip install mysql-connector-python.
  2. Create a database and tables for your bot.
  3. Connect bot to database and store/retrieve data.
  4. Test CRUD operations through bot commands.
SQLite Tutorial

Events, Listeners & Advanced Commands

Description: Implement on_message, on_member_join, and advanced command features.

  1. Use @bot.event to listen to events.
  2. Create multiple commands with arguments and checks.
  3. Test permission checks, cooldowns, and error handling.

Phase 5 — Hosting & Security

Hosting on Replit / Railway

Description: Deploy your bot or Python scripts online 24/7.

  1. Sign up on Replit or Railway.
  2. Upload your bot files and requirements.txt.
  3. Configure environment variables for token.
  4. Start bot and ensure it runs continuously.

Using .env Files

Description: Securely store your Discord token and sensitive info.

  1. Create a .env file in your project.
  2. Add DISCORD_TOKEN=your_token_here.
  3. Install pip install python-dotenv.
  4. Load token in code: from dotenv import load_dotenv; load_dotenv().
python-dotenv Docs
